# Сборка для Windows x64

Скачайте репозиторий через **Code → Download ZIP** и распакуйте его целиком. Откройте папку `build`, дважды щёлкните по `unpack-windows.cmd` и запустите появившийся `KulturnySloy.exe`.

Скрипт собирает архив из семи частей и проверяет его контрольную сумму перед распаковкой. Для распаковки используется системный `tar.exe` из Windows 10 или 11.
