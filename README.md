# Культурный слой

Ярослав Тальник, археолог из 2391 года, ведёт приёмку вторсырья в Пихтовом 1983-го. Появление компаса, который он уже видел на раскопе, даёт ему первую зацепку о собственном будущем.

## В рабочей папке

- [KulturnySloy.exe](build/KulturnySloy.exe) запускает игру на Windows x64. Откройте файл двойным щелчком в Explorer. В главном меню можно пройти пролог, начать первую неделю или продолжить с автосохранения.
- Для запуска версии из GitHub смотрите [инструкцию распаковки Windows-сборки](build/README.md).
- [Трек-лист разработки](TRACKER.md) показывает, что готово и что запланировано.
- [Проект Godot](game/project.godot) и [инструкция запуска](game/README.md) находятся в `game/`.
- В `sources/` лежат оригинальные PDF, DOCX, ZIP и README из коммита `835bf221`. Архив содержит исходную версию прототипа.
